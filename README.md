# Product Information Platform

## About the Project
The Product Information Platform is a web application developed using Python and Django. It allows users to submit product information and view the stored products.

## Features
- Add new product information.
- Display products in a table.
- Validate submitted data.
- Confirm the accuracy of product information.
- Manage products through the Django admin interface.

## Technologies Used
- Python
- Django
- HTML
- CSS
- SQLite

## Data Fields
The platform collects the following information:
- Product ID
- Product Name
- Category
- Price
- Quantity in Stock
- Information Accuracy Confirmation

## How to Run the Project Locally
1. Clone the repository.
2. Open the project folder.
3. Install Django.
4. Run database migrations.
5. Start the development server.

Commands:

```bash
pip install django
python manage.py migrate
python manage.py runserver
```

Open `http://127.0.0.1:8000/` in your browser.
